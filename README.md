# Поиск похожих фильмов

Проект посвящён сравнению нескольких методов поиска фильмов, похожих по содержанию.

В работе сравниваются три подхода:

1. **Genres baseline** — фильм представляется бинарным вектором жанров.
2. **TF-IDF** — используются текстовые описания фильмов (`overview`).
3. **Sentence Transformer** — описания преобразуются в семантические эмбеддинги с помощью предобученной модели `all-MiniLM-L6-v2`.

Для поиска похожих фильмов во всех трёх подходах используется **cosine similarity**.

## Данные

В проекте используются два источника данных:

- **The Movies Dataset** — названия, жанры, описания и годы выпуска фильмов;
- **MovieLens Tag Genome** — профили фильмов, состоящие из 1128 пользовательских тегов.

После подготовки и сопоставления датасетов итоговая выборка составила **8577 фильмов**.

MovieLens Tag Genome не используется при построении рекомендаций и служит только для оценки их качества.

## Оценка качества

Для оценки используется proxy-метрика **Mean Tag Similarity@10**.

Для каждого фильма:

1. Метод формирует Top-10 похожих фильмов.
2. Tag Genome-вектор исходного фильма сравнивается с Tag Genome-векторами рекомендаций.
3. Вычисляется среднее cosine similarity для десяти рекомендаций — `Tag Similarity@10`.
4. Значения усредняются по всем фильмам — `Mean Tag Similarity@10`.

## Результаты

| Метод | Mean Tag Similarity@10 |
|---|---:|
| Genres baseline | **0.7085** |
| Sentence Transformer | 0.6884 |
| TF-IDF | 0.6668 |

Жанровый baseline также показал лучший результат для **5187 фильмов (60.48%)**, Sentence Transformer — для **2483 (28.95%)**, а TF-IDF — для **907 (10.57%)**.

По выбранной proxy-метрике лучший результат показал простой метод рекомендаций по жанрам.

## Streamlit-приложение

Для демонстрации итогового метода реализовано приложение на Streamlit.

Пользователь выбирает фильм и количество рекомендаций, после чего приложение рассчитывает cosine similarity по жанровым признакам и выводит наиболее похожие фильмы.

## Запуск приложения

### 1. Клонировать репозиторий

```bash
git clone https://github.com/Kimkonge/MIPT-Movies-recommendations.git
cd MIPT-Movies-recommendations
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. Запустить Streamlit

```bash
streamlit run app.py
```

После запуска приложение будет доступно в браузере по локальному адресу, указанному Streamlit.

## Зависимости

Основные зависимости приложения:

- `streamlit`
- `pandas`
- `scikit-learn`

Полный список находится в `requirements.txt`.
